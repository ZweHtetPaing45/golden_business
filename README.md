# ကိုအောင်မျိုး ရွှေသန့်စင်လုပ်ငန်း ဝဘ်ဆိုက်

မြန်မာဘာသာဖြင့် ဖန်တီးထားသော စာမျက်နှာ ၇ မျက်နှာပါ အငြိမ်ဝဘ်ဆိုက်ဖြစ်သည်။ HTML5၊ CSS3၊ Bootstrap 5 နှင့် Vanilla JavaScript ကိုသာ အသုံးပြုထားပြီး build အဆင့် မလိုအပ်ပါ။

## ဖိုင်ဖွဲ့စည်းပုံ

- `index.html` — ပင်မစာမျက်နှာ
- `about.html` — ကျွန်ုပ်တို့အကြောင်း
- `services.html` — ရွှေသန့်စင်ဝန်ဆောင်မှု
- `gold-buying.html` — ရွှေအမှိက်ဝယ်ယူမှု
- `gold-extraction.html` — လုပ်ခဖြင့် ရွှေသန့်စင်ထုတ်လုပ်မှု
- `owner.html` — လုပ်ငန်းရှင်မိတ်ဆက်
- `contact.html` — ဆက်သွယ်ရန် ဖုန်းနံပါတ်နှင့် လုပ်ငန်းလိပ်စာ
- `css/style.css` — အရောင်ပုံစံနှင့် မျက်နှာပြင်အရွယ်အစားအလိုက် ဒီဇိုင်း
- `js/main.js` — မြန်မာဂဏန်းဖြင့် နှစ်ပြသမှု
- `assets/images/owner.jpg` — အသုံးပြုသူပေးထားသော လုပ်ငန်းရှင်ဓာတ်ပုံ
- `assets/images/logo.svg` — လုပ်ငန်းသုံး အမှတ်တံဆိပ်ပုံ

## စက်တွင်းတွင် ဖွင့်ရန်

ဖိုင်များကို တိုက်ရိုက်ဖွင့်နိုင်သော်လည်း Bootstrap နှင့် မြန်မာဖောင့်များအတွက် အင်တာနက်လိုအပ်သည်။ PowerShell တွင် ပရောဂျက်၏ `outputs` ဖိုဒါသို့ သွားပြီး အောက်ပါအမိန့်ကို အသုံးပြုပါ။

```powershell
cd outputs
python -m http.server 8000
```

ပြီးလျှင် `http://localhost:8000` ကို browser တွင် ဖွင့်ပါ။

## ပြင်ဆင်ရန်နှင့် ဆက်သွယ်ရန်

- ဖုန်းနံပါတ်၊ လိပ်စာ၊ ဝန်ဆောင်မှုနှင့် ဝန်ဆောင်ခအချက်အလက်များကို HTML ဖိုင်များအတွင်း ပြင်ဆင်နိုင်သည်။ လက်ရှိထည့်ထားသော ဖုန်းနံပါတ်မှာ ၀၉ ၉၄၁၁၀၁၁၂၅ ဖြစ်သည်။
- ဆက်သွယ်ရန်စာမျက်နှာတွင် ဖောင်မပါဝင်ပါ။ ဖုန်းခေါ်ဆိုရန်ခလုတ်နှင့် လုပ်ငန်းလိပ်စာကိုသာ ထည့်သွင်းထားသည်။
- Bootstrap၊ Bootstrap Icons နှင့် Noto Sans Myanmar တို့ကို CDN မှ ရယူသောကြောင့် အင်တာနက်ချိတ်ဆက်မှု လိုအပ်သည်။

## တင်သွင်းအသုံးပြုရန်

`outputs` ဖိုဒါအတွင်းရှိ ဖိုင်နှင့်ဖိုဒါအားလုံးကို static hosting ၏ public root သို့ ကူးတင်ပါ။ `index.html` သည် ပင်မစာမျက်နှာဖြစ်သည်။ HTTPS အသုံးပြုဖွင့်ပြီး ဝန်ဆောင်မှုအချက်အလက်၊ ဖုန်းနံပါတ်နှင့် တည်နေရာတို့ကို ထုတ်ဝေမီ ပြန်လည်စစ်ဆေးပါ။
